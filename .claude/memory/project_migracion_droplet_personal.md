Cesar esta migrando, por su cuenta y como reto personal (separado y en paralelo a [[project_migracion_nextjs_brandon]]), las herramientas de este repo desde Streamlit Cloud hacia un droplet propio. Piezas del plan:

- Acceso a la BD readonly (`icarus`) via Cloud SQL Auth Proxy usando su **login personal de Google** (`gcloud auth application-default login`) — pero solo para abrir el tunel de red (requiere `roles/cloudsql.client` via ADC). El login a Postgres en si NO es IAM end-to-end: ver [[reference_eliminarbat_db_auth_mechanism]] para el detalle real (contradice la suposicion original de este memory).
- Droplet encendido 24/7 (no scale-to-zero); la conexion a la BD se abre solo cuando hay una consulta.
- Frontend/backend: **React 19 + Vite + Tailwind CSS v4** (frontend) y **Python 3.12 + FastAPI** (backend) — mismo stack que su otro proyecto personal "Solidus Terminal P2P" (ver [[project_solidus_terminal_p2p]]), deliberadamente distinto del Next.js/Supabase de Brandon.
- Proveedor de droplet: **DigitalOcean**. Registrador de dominio: **Cloudflare Registrar**.
- Primera prueba de concepto: la herramienta **Consulta Extensiones** (la que origino todo esto, por el user `retools_reporting` roto — ver [[reference_notion_bd_retool_findings]]).
- Migracion incremental del resto de herramientas, una por una, dejando Streamlit de respaldo hasta validar cada una.
